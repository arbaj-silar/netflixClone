# Netflix Clone 🎬

A full-stack Netflix UI clone built with Java Servlets and JSP.

## 🚀 Features
- User Registration & Login with session management
- Dynamic homepage with movie/show listings  
- Video player page for content streaming
- MVC Architecture using Servlets + JSP
- Responsive UI with HTML/CSS

## 🛠️ Tech Stack
- **Backend**: Java, Servlets, JSP
- **Frontend**: HTML5, CSS3, JavaScript
- **Server**: Apache Tomcat 10
- **IDE**: Eclipse
- **Version Control**: Git & GitHub

## ⚙️ How to Run Locally
1. Clone: `git clone https://github.com/Arbaj-Silar/netflixClone.git`
2. Import into Eclipse as `Dynamic Web Project`
3. Add project to Apache Tomcat server
4. Run server → Visit `http://localhost:8083/netflixClone`
